## 如何使用

### 1. 启动开发服务器
```bash

cd /home/jian/project/New-CRM
source Pury_CRM/bin/activate

# 启动服务器
python manage.py runserver

# 访问
# 前端: http://localhost:8000
# 管理后台: http://localhost:8000/admin
```

### 2. 访问管理后台
1. 打开浏览器访问: http://localhost:8000/admin
2. 使用管理员账号登录:
   - 用户名: `admin`
   - 密码: `admin123`
3. 可以管理所有数据模型

### 3. 常用命令
```bash
# 激活环境
source Pury_CRM/bin/activate

# 创建新的迁移
python manage.py makemigrations

# 应用迁移
python manage.py migrate

# 创建超级用户
python manage.py createsuperuser

# Django Shell
python manage.py shell

# 检查项目
python manage.py check

# 查看所有 URL
python manage.py show_urls  # 需要安装 django-extensions
```

## 故障排除

### 如果数据库连接失败
```bash
# 检查容器是否运行
docker ps | grep pury-crm-db

# 如果没有运行，启动它
docker start pury-crm-db

# 检查日志
docker logs pury-crm-db
```

### 如果需要重置数据库
```bash
# 1. 停止并删除容器
docker stop pury-crm-db
docker rm pury-crm-db

# 2. 重新创建容器
docker run --name pury-crm-db \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_DB=pury_crm \
  -p 5433:5432 \
  -d chaitin-registry.cn-hangzhou.cr.aliyuncs.com/chaitin/postgres-zhparser:17.6-bookworm

# 3. 重新运行迁移
source Pury_CRM/bin/activate
python manage.py migrate

# 4. 重新创建超级用户（使用之前的 shell 脚本）
```

### 如果虚拟环境有问题
```bash
# 重新激活
source Pury_CRM/bin/activate

# 检查 Python 版本
python --version

# 检查已安装的包
pip list
```
